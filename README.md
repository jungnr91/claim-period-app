# 법령나침반 — 국가채권 규정 근거 찾기와 교육용 기간 계산

공개 코드 저장소: https://github.com/jungnr91/claim-period-app

이 저장소에는 소스·테스트·교육용 가상 샘플과 빌드 설정만 포함합니다. **`dist/`의 설치 EXE와 실제 업무자료·문제정의서는 게시하지 않습니다.** 아래 설치 파일 경로는 로컬에서 빌드한 경우의 경로이며, GitHub Release로 제공하는 다운로드가 아닙니다. 정부·국방부의 공식 프로그램이 아닌 교육용 시제품입니다. 새 PC에서는 `git clone https://github.com/jungnr91/claim-period-app.git` 후 해당 폴더에서 `npm install`, `npm start`로 실행할 수 있습니다.

`problem(3).md`와 국가채권 업무문제 정의서를 바탕으로 만든 **별도의 Electron 시제품**입니다. 화면은 HTML·CSS·JavaScript로 만들었습니다. 사용자가 입력한 공개 조문 안에서 문자열 후보를 찾고, 가상 기준일로 **5년과 10년을 나란히** 단순 계산합니다. AI API, 네트워크 검색, 실제 사건·내부 시스템 접근은 없습니다.

## 설치용 EXE (일반 사용자)

`dist/claim-period-reference-setup-0.2.0.exe`를 실행하여 설치 위치를 선택하세요. 설치 후 바탕화면·시작 메뉴의 **법령나침반 교육용**에서 실행할 수 있습니다. Node.js와 npm은 필요 없습니다. 이 빌드의 SHA-256 확인값은 `dist/SHA256-0.2.0.txt`에 있습니다.

**주의:** 설치 EXE에는 코드 서명이 없습니다. 현재 개발 PC는 기업용 Code Integrity 정책으로 새로 만든 서명되지 않은 배포용 실행 파일을 차단하므로, **설치 및 설치된 EXE의 실행은 여기서 검증하지 못했습니다.** 앱에 포함되는 파일은 기존 Electron 개발 실행 환경에서 드래그 앤 드롭·DOCX·PDF 검색과 날짜 계산을 검증했습니다. 기관 PC에서는 무단 우회하지 말고 승인된 배포·코드 서명 절차를 확인하세요.

## 실행

```powershell
cd 'C:\Users\NHI\Desktop\pdf to hwp\claim-period-app'
$env:PATH = 'C:\Program Files\nodejs;' + $env:PATH
npm install
npm start
```

Node.js 20 이상이 필요합니다. `npm install` 시 개발용 Electron 다운로드에 인터넷 접속이 필요하지만 **앱 자체는 로컬 오프라인 실행**입니다. 기관 PC의 설치·반입 규정과 승인을 먼저 확인하세요.

테스트: `npm test` (문서 추출·기간 계산·검색 로직), `npm run test:electron` (공개 문서 드래그 앤 드롭·화면 계산 검증). 개발자가 다시 EXE를 빌드할 때는 `npm run build:win`을 사용하며, 빌드마다 해시를 새로 기록합니다. 이 스크립트는 패키지를 만들고 NSIS 3 컴파일러(설치되어 있거나 electron-builder 캐시에 있는 경우)로 설치 파일을 **실행 없이** 묶습니다. 설치 EXE에 코드를 서명하려면 별도의 승인된 절차가 필요합니다.

## 사용법

1. **규정 근거 찾기:** 공개 원문을 준비해 TXT·MD·DOCX·글자가 포함된 PDF(파일당 8MB, PDF 15쪽 이하)를 업로드 영역으로 끌어다 놓거나 파일을 선택하세요. 가상 질문이 입력돼 있으면 근거 후보를 자동으로 다시 찾습니다. 자료 카드 위에 한 파일을 놓으면 해당 칸을 교체합니다(기존 내용이 있을 때 확인을 요청). **법령명·시행일·공식 링크는 파일에서 추정하지 않고 비웁니다.** 반드시 확인 후 직접 적으세요. URL만으로 원문을 자동 다운로드하거나 출처를 검증하지 않습니다. `공개 조문 예시 채우기`는 한 번에 가상 검색을 체험하는 기능입니다.
2. **기간 참고 계산:** 왼쪽 메뉴에서 화면을 전환해 `예시 날짜로 체험`하거나 가상 기준일과 초일 산입 여부를 선택하세요. 국가재정법 제96조 제1항의 5년과 민법 제162조 제1항의 10년을 **비교용 말일**로 나란히 보여줍니다.

`samples/`에는 **실제 법령이 아닌 교육용 가상 문장**을 담은 TXT·MD·DOCX·PDF가 있습니다. 이미지형 스캔 PDF는 이 앱에서 OCR하지 않으므로 명확히 오류를 표시합니다. 원문을 추출하지 못하면 검색 결과나 시행일을 만들어내지 않습니다. 실제 사건자료·내부 규정은 넣지 마세요.

법령 참조는 국가법령정보센터에서 2026-10-21 확인한 [국가재정법 제96조](https://www.law.go.kr/LSW/lsLinkProc.do?chrClsCd=010202&datClsCd=010102&gubun=admRul&joNo=009600002&lsId=34956&lsNm=%EA%B5%AD%EA%B0%80%EC%9E%AC%EC%A0%95%EB%B2%95&mode=10)(2026-09-11 시행 판본), [민법 제162조](https://www.law.go.kr/lsLinkProc.do?joNo=016200&lsNm=%EB%AF%BC%EB%B2%95&mode=11)(2026-03-17 시행 판본)를 기반으로 합니다. 법령은 개정될 수 있으니 최신 판본을 재확인해야 합니다.

## 반드시 알아둘 점

**이 앱은 시효 완성 여부나 적용 법령을 판단하지 않습니다.** 민법 일반채권 10년이 국가채권에 당연히 적용되는 것은 아닙니다. 국가 금전채권에는 별도 규정이 없는 경우 국가재정법상 5년 규정이 있을 수 있으며 채권별 다른 법률도 확인해야 합니다. 기산일 자체의 판단, 시효 중단·정지·연장, 소송·납입고지, 토요일·공휴일(민법 제161조), 신구 법령의 적용은 반영하지 않았습니다. 계산 결과는 **가상 날짜의 교육용 달력 참고값**입니다. 실제 사건, 채무자 이름·주소·재산, 비공개 원문은 입력하지 마세요. 기관 승인 없이 실제 업무자료를 외부 AI에 보내거나 프로그램을 내부망에 반입하지 마세요.
